Linux Fundamentals

Overview

Completed my initial hands-on training in Linux fundamentals using Ubuntu 26.04 LTS. Practised essential Linux terminal commands and developed an understanding of filesystem navigation, file management, and basic system inspection.

Topics Learned and Practised

- Terminal and Shell: Understanding command-line interaction.
- Navigation: Using "pwd", "cd", "ls", and "ls -la".
- Directory Management: Creating directories with "mkdir".
- File Management: Creating, copying, moving, and renaming files using "touch", "cp", and "mv".
- File Operations: Reading files with "cat" and writing content using "echo".
- Output Redirection: Understanding ">" (overwrite) and ">>" (append).
- Filesystem Paths: Understanding absolute and relative paths.
- System Information: Inspecting disk space, memory, and system uptime using "df -h", "free -h", and "uptime".
- User Information: Identifying the current user using "whoami".
- System Information: Examining kernel and system details using "uname -a".
