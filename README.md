DevOps Learning Journey

From Beginner to DevOps Engineering, Cloud Engineering, and DevSecOps

Welcome to my public, hands-on technical learning journey.

This repository documents my progress as I develop practical skills in Linux administration, networking, Git and GitHub, scripting, cloud infrastructure, containerization, CI/CD, Infrastructure as Code, monitoring, security, and disaster recovery.

My goal is to develop a strong technical foundation, demonstrate my abilities through practical projects, and eventually build a sustainable managed cloud and DevOps services business.

Learning Philosophy

I believe in learning by doing.

My approach is to:

1. Understand the fundamentals before adopting advanced tools.
2. Practise each concept in a real development environment.
3. Document commands, configurations, results, and lessons learned.
4. Test my work instead of assuming it is correct.
5. Use Git and GitHub to track progress.
6. Learn secure configuration and responsible administration.
7. Build progressively more realistic projects.
8. Be transparent about my current abilities and limitations.

Learning Environment

My primary learning environment is Ubuntu Linux.

I also use Windows 10 for selected cross-platform tasks and Termux with Ubuntu on my Android phone for portable Linux practice.
